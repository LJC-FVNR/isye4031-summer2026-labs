# ISYE 4031 Module 07 JupyterLite: Difference-in-Differences

This folder is the student-facing JupyterLite source for Module 07.
Open `files/00_START_HERE.ipynb` first.

This module connects dummy variables, interaction terms, panel data,
fixed effects, and causal interpretation through
Difference-in-Differences.

Build it from this directory with:

```powershell
jupyter lite build --lite-dir .
jupyter lite check --lite-dir .
jupyter lite archive --lite-dir .
```

The archive command produces `_output/software_jupyter_lite-jupyterlite.tgz`.
