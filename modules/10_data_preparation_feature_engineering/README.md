# ISYE 4031 JupyterLite: Data Preparation and Feature Engineering

This directory is the student-facing JupyterLite source for `10_data_preparation_feature_engineering`.
Open `files/00_START_HERE.ipynb` first.

Build and validate from this directory:

```powershell
jupyter lite build --lite-dir .
jupyter lite check --lite-dir .
jupyter lite archive --lite-dir .
```

Only this directory should be copied to the public course repository under
`modules/10_data_preparation_feature_engineering/`. Generated `_output/` files are build artifacts and
should not be committed.
