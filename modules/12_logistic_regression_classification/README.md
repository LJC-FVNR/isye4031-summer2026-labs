# ISYE 4031 JupyterLite: Logistic Regression and Classification

This directory is the student-facing JupyterLite source for `12_logistic_regression_classification`.
Open `files/00_START_HERE.ipynb` first.

Build and validate from this directory:

```powershell
jupyter lite build --lite-dir .
jupyter lite check --lite-dir .
jupyter lite archive --lite-dir .
```

Only this directory should be copied to the public course repository under
`modules/12_logistic_regression_classification/`. Generated `_output/` files are build artifacts and
should not be committed.
