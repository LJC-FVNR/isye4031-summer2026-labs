# ISYE 4031 JupyterLite: Shrinkage Methods: Ridge and LASSO

This directory is the student-facing JupyterLite source for `13_shrinkage_ridge_lasso`.
Open `files/00_START_HERE.ipynb` first.

Build and validate from this directory:

```powershell
jupyter lite build --lite-dir .
jupyter lite check --lite-dir .
jupyter lite archive --lite-dir .
```

Only this directory should be copied to the public course repository under
`modules/13_shrinkage_ridge_lasso/`. Generated `_output/` files are build artifacts and
should not be committed.
